Where I'm heading

Most of what I've built so far lives in the browser. What I want to build next is machine learning: systems that learn their behaviour from data instead of from rules I write by hand.

The thread through my web work — React interfaces, a form-autofill system for an e-governance course, a search site that won a college competition — is making software a person can use without being taught how. I'm learning ML the same way I learned the web: by finishing projects rather than collecting tutorials.

I'm applying for Master's study in China because I want to do this work with real supervision and a research group around me, rather than alone at my desk in Kathmandu.
